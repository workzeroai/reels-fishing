# 릴스 낚시 (Reels Fishing)

인스타그램 릴스 기획을 낚시에 빗댄 브라우저 3D 게임. 설치 없이 휴대폰·PC에서 바로 플레이.

**▶ 플레이: https://workzeroai.github.io/reels-fishing/**

## 하는 법

1. **세트 고르기**: 실제로 올린 릴스·커버 문구·리드마그넷 조합 3개 중 하나
2. **섬 걷기**: 수달을 방향키·WASD(휴대폰은 화면 끌기)로 움직여 풍경이 다른 낚시 자리로. 자리마다 사는 물고기(크리에이터·마케터·AI 초보)가 다름
3. **낚시**: 찌가 쑥 잠기면 탭(스페이스) → 연타로 감고, 물고기가 차고 나가면 화살표 방향으로 버티기. 잘못 버티면 줄이 끊김
4. **한 판 = 찌 3번** → 결과에서 실제 릴스 기록과 비교

## 실제 기록에 맞춘 계산

게임 속 수치는 실제 릴스 4편의 기록(인스타 인사이트의 조회한 사람·팔로우, 자료 DM 발송 수)에 맞춘 단순화 모델(`sim.js`)이 정한다. 실제로 올린 조합을 고르면 조회한 사람·팔로우·자료 DM이 네 편 모두 실제 값의 ±15% 안에 들어온다.

| 릴스 | 조회한 사람 | 팔로우 | 자료 DM |
|---|---|---|---|
| MCP 5선 (09-27) | 59,629 | 662 | 603 |
| 디자인 3선 (10-04) | 75,216 | 540 | 543 |
| 블로그 키워드 (10-15) | 9,216 | 282 | 354 |
| Claude 101 (10-18) | 2,464 | 35 | 50 |

## 구조

빌드 단계 없는 ES 모듈. Three.js r170·lil-gui는 jsDelivr에서 불러오고, 3D는 전부 코드로 그린다(이미지는 릴스 커버 4장, 소리는 Web Audio 합성으로 음원 파일 0개).

| 파일 | 맡은 일 |
|---|---|
| `index.html` | 화면 틀과 스타일. 스크립트는 `js/main.js` 하나만 부름 |
| `sim.js` | 계산 규칙(떼·입질·감기·실제 기록·추천 세트·구역). 화면과 무관 |
| `sim.test.mjs` | `sim.js` 테스트 26개 |
| `js/main.js` | 게임 진행(단계·입력·카메라·낚싯대·물고기·결과)과 모듈 연결 |
| `js/island.js` | 섬 지형·길·숲·네 낚시 자리 풍경 |
| `js/otter.js` | 수달 모양과 걷기·앉기 동작 |
| `js/env.js` | 물·하늘·먼 섬·갈매기 |
| `js/zones.js` | 앞바다 세 지형(암초·해초 숲·모래톱) |
| `js/audio.js` | 장면별 배경음악·효과음·줄 긴장·발소리 합성 |
| `js/i18n.js` | 한국어/English 문구 |
| `js/util.js` | 공용 도구(난수·잡음·색) |
| `dev/*.html` | 섬·수달·소리만 따로 보는 미리보기 |

## 실행·테스트

```bash
python3 -m http.server   # http://localhost:8000/
node --test              # sim.test.mjs 26개
```

테스트가 고정하는 것: 실제 기록 재현(조회한 사람·팔로우·자료 DM ±25%), 감기 난이도(플레이 방식별 200판 시뮬레이션: 제대로 버티기·연타만·반대로 버티기·안 버티기), 구역 간격, 추천 세트 구성.
